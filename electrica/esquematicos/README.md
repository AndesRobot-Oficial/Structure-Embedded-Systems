# Esquemáticos

- Archivo fuente (ej. proyecto de KiCad) **y** un PDF exportado para revisarlo sin software.
- Incluir el **diagrama de bloques de potencia**: batería → protecciones → distribución → reguladores → consumidores.
- La **parada de emergencia** debe cortar la potencia de los motores (base y brazo) y estar claramente indicada.
